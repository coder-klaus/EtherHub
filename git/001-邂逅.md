git文件分为四个状态 「 一般忽略未追踪，也说只有三个分区 」

1. 未追踪 => 新建文件，也就是那些没有被add过的文件
2. 已修改 => 被git追踪的文件发生了修改
3. 已暂存 => 被加入git暂存区文件
4. 已提交 => 加入git本地版本库文件

**未追踪 → 已暂存 → 已提交** 或 **已修改 → 已暂存 → 已提交**

新建文件默认就是未追踪，只有该文件被纳入git对象区才会被git真正管理

如果是一个空目录，git add 命令执行的时候会自动忽略该目录，因为没有提交的必要

git的分区

1.  工作区
2. 暂存区「 索引区 」
3. 对象区

其中 本地版本库 = 暂存区 + 对象区

暂存区存在的意义是可以不用一次提交所有修改。同时可以临时缓存当前修改。以便进行新功能的开发
