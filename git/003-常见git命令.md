## 初始化

```shell
# 初始化git仓库 => 在当前工作目录下生成.git目录，其就是本地仓库
# git命令操作的都是.git目录下的目录或文件夹
git init
```

执行该命令后，会创建一个`.git`目录和一个主分支



### .git

1. 只要当前目录存在`.git`。则当前目录及其子目录都可以被git所管理
2. **.git** 目录包含了 Git 用来识别和管理项目版本的所有文件和文件夹
3. 运行的所有 Git 命令，本质上都是通过这个目录下的这些文件和结构来实现的



### 主分支

在 Git 中，所有的操作都必须在某个分支（**branch**）上进行。

默认生成的主分支一般名为`master` 或`main`

主分支一般作为生产分支，通常是用于代码的最终发布。例如，在公司中，项目的上线部署或发布到生产环境时，通常都会使用  主分支来进行操作。



## 查看状态

```shell
git status
```



## 文件操作

```shell
git add <file | .> # 工作区 => 暂存区 「 . 表示任意文件 」

git rm --cached <file> # 暂存区 => 工作区 「 首次提交，即没有HEAD的时候 」
git restore --cache <file> # 暂存区 => 工作区 「 有首次提交的时候 」
```

```shell
git commit # 提交信息 「 自动开启vi 」
git commit -m '提交信息'
git commit -am '提交信息' # 该命令只能用于已追踪文件
```
