挂载点 => 渲染后内容会作为挂载点的innerHTML插入 「 会替换原本内容 」

+ vue  一般为 `div#app`
+ react 一般为 `div#root`



指定视图方式 『 先看el => 没有再看mount  』

+ el 「 值可以是DOM元素，也可以是一个css选择器 => 一般传递的是id选择器 」
  + 当我们传入一个选择器字符串（如 `'#app'`）时，
  + Vue 会自动通过 `document.querySelector` 获取对应的 DOM 元素。

+ mount



指定模板 『 先看template => 没有使用挂载点的innerHTML 』

+ `template`
+ 挂载点的 `innerHTML`
+ `render` 方法

> 1. 任何渲染方式都会转换为render方法，该方法会返回VNODE
>
> 2. 所以三者同时存在，以`render`优先级最高

```js
new Vue({
  // h 就类似于react中的 createReactElement
  // 调用render获取到的结果是vnode对象
  render: h => h('div', {}, 'Hello Vue!')
}).$mount('#app');
```

工程化项目中，最为常用的设置是

1. 视图在SFC中指定，实际编译为render方法
2. 挂载通过`$mount`，目的是创建Vue实例后可以进行额外操作「 如挂载路由和全局状态管理 」



Vue 会将渲染后的内容插入到挂载点，并替换原本内容。

+ `vue`  一般为 `div#app`
+ `react` 一般为 `div#root`



挂载点中的内容是应用的一部分，但挂载点本身不属于 web app



Vue 的视图挂载方式：

- 如果指定了 `el`，Vue 会自动挂载到指定的 DOM 节点。

- 如果没有指定 `el`，需要手动调用 `vm.$mount()`。

  

Vue 的模板渲染优先级：

- 优先使用 `render` 方法。
- 如果没有 `render` 方法，则使用 `template`。
- 如果没有 `template`，Vue 会尝试使用挂载点的 `innerHTML`。

所有渲染方式最终都会被转换为 `render` 方法，`render` 方法返回虚拟 DOM 节点（VNode）。
