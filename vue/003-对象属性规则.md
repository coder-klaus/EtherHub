一个对象是由多组键值对组成的，这些键值对（成员）是有一定规则限制的



可以通过 `Object` 的静态方法 `Object.getOwnPropertyDescriptor` 来查看对象某个成员的描述信息

这个方法返回的是一个描述对象（Descriptor），包含当前成员的规则限制



通过 `Object.getOwnPropertyDescriptor(obj, 'x')`，我们可以查看 `x` 的规则限制。描述对象中包含以下几个属性：

- `configurable`：如果为 `true`，表示该成员可以通过 `delete` 删除 或 可以修改属性描述符
- `enumerable`：如果为 `true`，表示该成员可以被枚举（如 `for...in` 或 `Object.keys`）。
- `writable`：如果为 `true`，表示该成员的值可以被修改。
- `value`：成员的实际值。



`Object.getOwnPropertyDescriptor` 只能查看对象自身的属性，如果不是自身属性，将返回`undefined`

- 通过常规手段添加的成员「 如直接定义在对象字面量中，或者通过赋值语句添加 」，规则一般是可枚举、可删除、可修改。
- 浏览器内置的成员（如 `toString`），规则一般是不可枚举，但可删除、可修改。



可以通过 `Object.getOwnPropertyDescriptors(obj)` 方法来获取对象所有成员的规则描述信息。这会返回一个包含所有成员描述的对象。



`Object.defineProperty` 的语法如下：

```javascript
Object.defineProperty(obj, prop, descriptor);
```

- 第一个参数：目标对象（如 `obj`）。
- 第二个参数：要定义或修改的成员名称（如 `y`）。
- 第三个参数：一个对象，用来指定该成员的规则（`configurable`、`enumerable`、`writable`、`value`）。

使用`Object.defineProperty`

1. 如果成员之前不存在，新增成员时，规则的默认值是 `false`。
2. 如果成员之前已经存在，修改规则时，未指定的规则会保持原样。



在谷歌浏览器中，有这样一个特性：

- 深颜色表示可枚举的成员。
- 浅颜色表示不可枚举的成员。



除了设置规则以外，`Object.defineProperty` 还有另一个重要作用：**数据劫持**。

数据劫持的核心是拦截对象成员的访问或修改行为，并注入自定义逻辑

```js
let obj = { x: 10, y: 20 };
Object.defineProperty(obj, 'x', {
  get() {
    console.log('访问了 x');
    return 100;
  },
  set(newValue) {
    console.log('修改了 x，新的值是', newValue);
  }
});
```



一旦成员被劫持，在控制台输出时，成员的值会显示为三个点 `...`。对象下面会有该成员的 `get` 和 `set` 标识。点击成员时，会触发 `get` 函数，从代理对象中获取值。

数据劫持的 `get` 和 `set` 函数 与  `writable` 和 `value` 是相互冲突的。设置了get和set的叫存取描述符。设置了value和writable的叫数据描述符
