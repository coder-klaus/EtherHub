在 Vue 中，无论是 Vue 2 还是 Vue 3，我们最常用的视图构建语法就是 `template` 语法。`template` 是 Vue 框架自己设计的一套语法，用来绑定数据和处理视图。

当然，除了 `template` 语法，Vue 也支持类似 React 的 JSX 语法，但 JSX 在 Vue 中使用得比较少。

而 `template` 语法中最主要的知识点有两个：

1. **小胡子语法**
2. **指令**

小胡子语法就是双大括号 `{{ }}`。Vue 的小胡子语法用于绑定数据。在小胡子语法中，可以嵌入 JavaScript 表达式计算后的结果值

需要注意的是，小胡子语法只能嵌入 JavaScript 表达式。因为它们属于操作语句，而不是表达式。表达式的特点是执行后会有返回值，而操作语句没有返回值。



小胡子中还可以运行一些在vue白名单中的全局方法，比如 `JSON.parse` 和 `JSON.stringify` 是可以运行的。



渲染规则

1. `undefined` 或 `null`，渲染结果是空字符串
2. 普通对象和数组会通过 `JSON.stringify` 转换为 JSON 字符串进行渲染
3. 其他数据类型会通过 `String` 转换为字符串进行渲染



对比一下 Vue 和 React 的数据绑定语法。在 React 中，单大括号 `{}` 的渲染规则是：

- 原始类型值中，除了数字和字符串会正常渲染，其他类型（如 `null` 和 `undefined`）会渲染为空。
- 对象类型值中，只有 `React.Element` 和数组可以正常渲染，其他对象类型会报错。
  + 数组是取出每一项后，单独进行渲染
