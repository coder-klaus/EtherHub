在 Tailwind 中，每个工具类都可以通过在类名前添加一个变体来实现条件应用，该变体描述了你想要针对的状态。

```css
bg-sky-500 hover:bg-sky-700
```



传统样式设置是为同一个样式设置不同状态样式

```css
.btn-primary {
  background-color: #0ea5e9;
}

.btn-primary:hover {
  background-color: #0369a1;
}
```

tailwindcss的实现和传统样式实现并不同，tailwindcss 是为不同状态下添加不同的样式。也就是实用类可以被有条件地应用

```css
.bg-sky-500 {
  background-color: #0ea5e9;
}

/*
	hover:bg-sky-700 这个类 会直接作为字符串进行解析
	其中特殊符号会加上 \ 进行转义
*/
.hover\:bg-sky-700:hover {
  background-color: #0369a1;
}
```



功能类前缀可以被叠加使用

```css
dark:md:hover:bg-fuchsia-600
```



Tailwindcss支持所有的伪类，具体可以查询官网对应[索引]((https://tailwindcss.com/docs/hover-focus-and-other-states#quick-reference)

```css
nth-[2n+1_of_li] => li:nth-of-type(2n+1)
```



一些常用的其它伪类:

1. :only-child、:first-of-type、:empty 等 => 元素在父元素中位置
2. :disabled、:invalid、:focus等 => 表单的各种状态

编译后的实现

```css
<ul>
  <!-- 
    通过peer标识同级元素
    peer标识默认标识，名称为 default
  -->
  <li class="peer">
    <a href="#">link</a>
  </li>
  <!-- peer标识元素的后代元素有a元素，则该元素设置背景 -->
  <li class="peer-has-[a]:bg-amber-300">2</li>
  <li>3</li>
</ul>

```
