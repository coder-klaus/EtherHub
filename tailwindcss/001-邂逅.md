Tailwind CSS 的核心设计理念 - 通过组合多个单一用途的实用类(utility classes)直接在 HTML 标记中构建复杂的组件

```css
mx-auto flex max-w-sm items-center
```



这种方式的优点:

1. 开发效率高 - 不需要在 HTML 和 CSS 文件之间切换,也不需要想类名
2. 修改安全 - 修改一个元素的样式不会影响其他元素
3. 代码可移植 - 样式和结构在一起,方便复制粘贴
4. 可维护性强 
   - 如果需要修改某个值，只需要修改设计系统中的定义，所有使用该值的地方都会自动更新
   - 使用统一的设计系统，例如使用的断点值等都是一致的
5. CSS 体积可控 - 由于实用类的复用性,不会随着项目增长而膨胀
6. 想比喻内联样式，支持状态样式「 hover， focus等 」 和 媒体查询等功能



在 Tailwind 中，你可以通过添加状态前缀来为元素的不同状态设置样式

```css
bg-blue-500 hover:bg-blue-700
```



Tailwind 使用移动优先的设计理念，默认样式应用于移动设备，然后通过断点前缀来为更大的屏幕添加样式



Tailwind 提供了两种方式来启用暗黑模式：

1. 基于系统偏好设置（media）

1. 基于类名切换（class）
