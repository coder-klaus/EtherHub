## :nth系列

### :nth-child

```css
/*
	nth-child 只考虑元素位置，不考虑元素类型
  + 界面中元素索引从1开始计算
  + n是从0开始计算
*/

/* 选中正数第二个元素 */
li:nth-child(2) {
  background: purple;
}

/* 奇数 */
li:nth-child(odd) {
  background-color: yellow;
}

/* 偶数 */
li:nth-child(even) {
  background-color: lightblue;
}

/* 选中序号为3n+1的元素 => 即 1, 4, 7 ... 个元素 */
li:nth-child(3n+1) {
  background: skyblue;
}
```

```css
/* 父元素的第二个子元素，无论这个子元素是什么类型的元素 */
:nth-child(2)
```



### :nth-of-type

```html
<style>
  /*
    nth-of-type 选择器匹配同类型的第n个元素
    + 界面中元素索引从1开始计算
    + n是从0开始计算
  */

  /* 选中第二个p元素 => 不是li元素 */
 /*  p:nth-of-type(2) {
    background: purple;
  } */

  /*
    选中奇数位置的li元素
    + 只考虑p元素，所以第一个p对应的索引为1，第一个p对应索引为2
    + 即使他们在ul的子元素中索引点都为奇数，但只有第一个会变色
  */
  /* p:nth-of-type(odd) {
    background-color: yellow;
  } */

  /* 选中偶数位置的li元素 */
  /* p:nth-of-type(even) {
    background-color: lightblue;
  } */

  /* 选中第3n+1个li元素 (1, 4, 7...) */
  /* li:nth-of-type(3n+1) {
    background: skyblue;
  } */
</style>

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
  <li>Item 4</li>
  <!-- 添加一些不同类型的元素来展示nth-of-type的特性 -->
  <p>Paragraph 1</p>
  <li>Item 5</li>
  <p>Paragraph 2</p>
  <li>Item 6</li>
</ul>
```

```css
/* 当前父元素的子元素中，无论那种类型，只要是该类型中的第三个元素，都会被选中 */
:nth-of-type(3) {
  background: purple;
}
```





```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>

      disabled 是在 readonly基础上 加上不可聚焦
      所以处于disabled状态的元素 也会被匹配到 :read-only 伪类
      因此本例中第一个和第二个 input元素的背景颜色都是 #foo
    */
    input:disabled + span {
      background: #4f4f4f;
    }

    /*
      注意html和js的属性名叫 readonly, 但是css对应的伪类名叫 :read-only
      如果元素同时存在 disabled 和 readonly 
      + 界面元素效果 以 disabled为主，因为disabled包含了readonly
      + 伪类样式结构，取决于设置元素的先后顺序和样式权重大小
    */
    input:read-only + span {
      background: #f00;
    }

    input:indeterminate + span {
      background: #0f0;
    }

    input:checked + span {
      background: #00f;
    }
  </style>
</head>
<body>
  <!-- disabled 表示元素完全不可用，用户无法聚焦或编辑 -->
  <div><input type="text" disabled value="disabled"> <span>disabled</span></div>

  <!-- readonly 表示元素是只读的，用户可以聚焦但不能编辑 -->
  <div> <input type="text" readonly value="readonly"> <span>readonly</span></div>
  
  <div> <input type="checkbox" id="indeterminate"> <span>indeterminate</span></div>

  <!-- checkd既可以在html元素上设置，也可以通过js设置 -->
  <div> <input type="checkbox" id="checked" checked> <span>checked</span></div>

  <script>
    const indeterminate = document.getElementById('indeterminate')
    // indeterminate 属性在 checkbox 中表示不确定状态 => 显示为 横杠
    // html元素上不存在 indeterminate属性，需要通过 js 设置
    indeterminate.indeterminate = true
   </script>
  </div>
</body>
</html>
```



## :has

`:has()` 是基于后代或子元素的状态来决定是否给当前元素设置样式

```css
/* 如果 <div> 内包含 <img>，则为该 <div> 设置样式 */
div:has(img) {
  background-color: lightblue;
}

/* 如果 <form> 内有一个聚焦的输入框，则为该 <form> 设置样式 */
form:has(input:focus) {
  border: 2px solid blue;
}

/* 如果 <input> 元素后跟一个 <span>，则为该 <input> 设置样式 */
input:has(+ span) {
  border-color: red;
}

/* 如果 <div> 内包含一个 <img>  或 后代中有一个聚焦的输入框，则应用样式 */
div:has(img, input:focus) {
  box-shadow: 0 0 10px gray;
}

/* 如果 <details> 元素包含一个展开的状态，则改变样式 */
details:has([open]) {
  background-color: lightyellow;
}
```
