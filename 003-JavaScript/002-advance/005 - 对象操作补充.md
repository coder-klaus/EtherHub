## defineProperty

1. 新增或修改属性
2. 对属性规则进行更粒度化的配置

```js
const user = {
  name: 'Klaus',
  age: 23
}

// 修改原本属性
// 参数一 - 需要修改的对象
// 参数二 - 需要修改的属性
// 参数三 - 属性描述符
// 返回值 - 修改后的对象
// 因为defineProperty 不是一个纯函数，会改变传入的对象，所以返回值很少使用
Object.defineProperty(user, 'name', {
  value: 'Alex'
})

// 添加属性
const obj = Object.defineProperty(user, 'address', {
  value: 'shanghai',
  enumerable: true
})

console.log(user.name) // => Alex
console.log(user.address) // => shanghai
console.log(obj) // => { name: 'Alex', age: 23, address: 'shanghai' }
```



![image.png](https://s2.loli.net/2025/02/19/r2Bf8gudM6potJs.png) 

通过直接赋值（如 `obj.prop = value`）来设置对象的属性时，JavaScript 会创建一个 **数据属性**，其默认行为如下：

- **`value` 属性**：等于赋值的值。
- 其他描述符（`writable`、`enumerable`、`configurable`）：默认值为 `true`。

```js
const obj = {};
obj.prop = 42;

// 输出某一个属性的属性描述符 => 属性不存在 则返回undefined
console.log(Object.getOwnPropertyDescriptor(obj, 'prop'));
/*
{
  value: 42,
  writable: true,
  enumerable: true,
  configurable: true
}
*/
```



通过 `Object.defineProperty` 显式定义属性时，描述符的默认行为如下：

- **`value` 属性**：如果未指定，则默认为 `undefined`。
- **`get` 和 `set` 属性**：如果未指定，则默认为 `undefined`。
- 其他描述符（`writable`、`enumerable`、`configurable`）：默认值为 `false`。

```js
const user = {};

Object.defineProperty(user, 'name', {
  value: 'Klaus'
})

// 输出对象所有属性对应的属性描述符对象
// => 只能输出 属性对象 自身的 非Symbol类型属性值 「 无论是否可枚举 」
console.log(Object.getOwnPropertyDescriptors(user));
/*
{
  name: {
    value: 'Klaus',
    writable: false,
    enumerable: false,
    configurable: false
  }
}
*/
```



- 如果属性的 `enumerable` 为 `true`，则该属性是 **可枚举的**，可以通过以下方式获取：
  - `Object.keys(obj)`（只返回可枚举的自有属性）。
  - `for...in`（返回可枚举的自有属性和继承属性）。
  - `JSON.stringify(obj)`（只序列化可枚举的自有属性）。
- 如果属性的 `enumerable` 为 `false`，则该属性是 **不可枚举的**，不会出现在上述方法的结果中



属性在浏览器控制台中的显示颜色 「 具体颜色取决于浏览器具体实现，这里以chrome为例 」

+ **可枚举属性** => 蓝色
+ **不可枚举属性**  => **浅蓝色（灰蓝色）**



## defineProperties

同时设置多个属性的属性描述符

```js
const user = {}

Object.defineProperties(user, {
  name: {
    value: 'Klaus',
    enumerable: true
  },

  age: {
    value: 23,
    enumerable: true
  }
})

console.log(user) // => { name: 'Klaus', age: 23 }
```



## 限制对象

```js
const user = {
  name: 'Klaus',
  age: 23
}

Object.preventExtensions(user) // 禁止扩展对象 => 不能添加新的属性
console.log(Object.isExtensible(user)) // false => 检测对象是否可扩展
```

```js
const user = {
  name: 'Klaus',
  age: 23
}

Object.seal(user) // 封闭属性 => 不能添加或删除属性，但是可以修改属性
console.log(Object.isSealed(user)) // true => 检测对象是否已封闭
```

```js
const user = {
  name: 'Klaus',
  age: 23
}

Object.freeze(user) // 冻结对象 => 不能修改对象的属性 「 不可以增删改 」
console.log(Object.isFrozen(user)) // true => 检测对象是否冻结
```



## 原型相关

```js
const obj = {
  name: 'Klaus',
  age: 23
}

const user = {}

Object.setPrototypeOf(user, obj) // 设置user的原型对象为obj对象

console.log(Object.getPrototypeOf(user) === obj) // true => 获取user对象的原型对象
```

```js
const proto = {
  name: 'Klaus',
  age: 23
}

// 创建一个原型是 proto 的对象
// 第二个参数是一个包含属性描述符的对象 => 设置的属性会被添加到新创建的对象上
const user = Object.create(proto, {
  friends: {
    value: ['Alex', 'Bob'],
    writable: true,
    configurable: true
  }
})
```

```js
const proto = {
  name: 'Klaus',
  age: 23
}

// 创建一个原型为 null 的对象 => 该对象没有原型 => 即是 顶层对象又是纯JavaScript对象
const user = Object.create(null)
```



如果需要修改原型链 推荐使用`Object.create` 来替代 `Object.setPrototypeOf` ，这是因为现代浏览器在创建对象原型链时会对其进行优化

+ 如果使用 `Object.setPrototypeOf`  则需要
  1. 破坏之前创建的原型链
  2. 创建新的原型链
  3. 重新进行优化

+ 而如果使用`Object.create`，则只需要
  1. 复用之前的原型链
  2. 只要对新增原型链进行优化



### 纯JavaScript对象

1. 通过`new Object` 或 `字面量` 写法 创建的 普通的 JavaScript对象
2. 即该对象的直接原型就是`Object.prototype` 或 `null` 「 没有原型 」



## 实例方法

### hasOwnProperty

```js
const obj = {
  name: 'Klaus',
  age: 23
}

const user = Object.create(obj)
user.address = 'shanghai'

// 判断属性是否属于对象自身
console.log(user.hasOwnProperty('name')) // => false
console.log(user.hasOwnProperty('address')) // => true
```



#### hasOwn

```js
const user = {
  name: 'Klaus',
  __proto__: {
    age: 23
  }
}

// hasOwn 是Object的静态方法，用于替代对象的实例方法 hasOwnProperty
console.log(Object.hasOwn(user, 'name')) // => true
console.log(Object.hasOwn(user, 'age')) // => false
```

```js
const user = Object.create(null, {
  name: {
    value: 'Klaus'
  }
})

// Object.hasOwn 作为静态属性，可以适用于直接原型为null的对象

// user的直接原型对象为null，无法调用对象通用属性和方法
console.log(user.hasOwnProperty('name')) // error

// 静态属性就不存在这个问题
console.log(Object.hasOwn(user, 'name')) // => true
```



### `in`

```js
const obj = {
  name: 'Klaus',
  age: 23
}

const user = Object.create(obj)
user.address = 'shanghai'

// in操作符 判断 属性是否存在于 对象的原型链上
console.log('name' in user) // => true
console.log('address' in user) // => true

// in操作符 可以 衍生出 for-in遍历 => 迭代自身和其原型链上的 可迭代 非Symbol 类型属性
// 在JavaScript中，内置属性都是不可枚举的，所以无法通过 for-in遍历得到
for (let key in user) {
  console.log(key)
  /*
    =>
      name
      age
      address
  */
}
```



### instanceOf

```js
function Person(name, age) {
  this.name = name
  this.age = age
}

function Student(name, age, sno) {
  Person.call(this, name, age)
  this.sno = sno
}

Object.setPrototypeOf(Student.prototype, Person.prototype)

const stu = new Student('Klaus', 23, 1810166)

// 实例 instanceof 构造函数 => 构造函数是否在实例的原型链上
console.log(stu instanceof Student) // => true
console.log(stu instanceof Person) // => true
```



#### isPrototypeOf

```js
const obj = {
  name: 'Klaus',
  age: 23
}

const user = Object.create(obj)

// A.isPrototypeOf(B) => A是否存在于B的原型链上
// isPrototypeOf 主要用于判断 实例和实例之间的关系，而 instanceof 判断的是 实例 和 构造函数之间的关系
console.log(obj.isPrototypeOf(user)) // => true
```
