## 概述

- 迭代器是一种对象，用于帮助我们遍历某个数据结构（如数组、链表、集合等），而不需要关心数据结构的具体实现方式。
- 它的行为类似于数据库中的“光标”，可以逐步遍历数据。
- 在JavaScript中，迭代器是一个满足了**迭代器协议 (Iterator Protocol)**的对象



### 迭代器协议

```js
const user = {
  friends: ['Alex', 'Klaus', 'Steven']
}

function genIterator(arr) {
  let index = 0

  // 返回一个迭代器对象
  return  {
    // next就是满足迭代器协议的方法
    next() {
      if (index < arr.length) {
        // 迭代器协议需要返回done和value组成的对象
        // + done为false表示没有结束 「 不写done属性是默认值为false 」
        // + value为当前索引位置的值 「 不写value属性是默认值为undefined 」
        return {
          done: false,
          value: arr[index++]
        }
      } else {
        return { done: true, value: 'finished' }
      }
    }
  }
}

// 生成迭代器对象
const iterator = genIterator(user.friends)

console.log(iterator.next()) // => { done: false, value: 'Alex' }
console.log(iterator.next()) // => { done: false, value: 'Klaus' }
console.log(iterator.next()) // => { done: false, value: 'Steven' }

// 迭代器结果，将永远返回相同对象 「 value为finished 是因为默认值为finished 」
console.log(iterator.next()) // =>{ done: true, value: 'finished' }
console.log(iterator.next()) // =>{ done: true, value: 'finished' }
```



在上述例子中，迭代器和对应需要迭代的对象是分离的。

如果迭代器本身就是需要迭代对象的一个属性时，该需要迭代的对象就是可迭代对象

```js
const user = {
  friends: ['Alex', 'Klaus', 'Steven'],

  // 通过Symbol.iterator定义迭代器方法
  // Symbol.iterator 在ECMA标准中的名称为 @@iterator 
  [Symbol.iterator]() {
    let index = 0

    // 调用方式为 user[Symbol.iterator]()，所以this为对象本身
    console.log(this === user) // => true

    return  {
      // 调用方式为[Symbol.iterator]().next()，所以需要使用箭头函数确保this指向对象
      next:() => {
        if (index < this.friends.length) {
          return {
            done: false,
            value: this.friends[index++]
          }
        } else {
          return { done: true }
        }
      }
    }
  }
}

// 任何的可迭代对象都可以通过for-of进行迭代
// for-of在迭代过程中会自动执行对象内部的[Symbol.iterator]方法
for (const name of user) {
  console.log(name)
}
/*
  =>
    Alex
    Klaus
    Steven
*/
```


一些内置的数据结构(如 String、Array、Map、Set、arguments对象、NodeList集合等)都是可迭代对象，默认就实现了迭代器方法 

```js
const arr = [1, 2, 3]

console.log(arr[Symbol.iterator]()) // => Object [Array Iterator] {}

const iterator = arr[Symbol.iterator]()
console.log(iterator.next()) // => { value: 1, done: false }
console.log(iterator.next()) // => { value: 2, done: false }
console.log(iterator.next()) // => { value: 3, done: false }
console.log(iterator.next()) // => { value: undefined, done: true }
```



### 应用场景

1. JavaScript中语法: for ...of、展开语法(spread syntax)、yield*、解构赋值(Destructuring_assignment) 「 对象的解构赋值除外 」
2. 创建一些对象时:new Map([Iterable])、new WeakMap([iterable])、new Set([iterable])、new WeakSet([iterable])
3. 一些方法的调用:Promise.all(iterable)、Promise.race(iterable)、Array.from(iterable)



```js
class Person {
 constructor(name, age, height) {
  this.name = name
  this.age = age
  this.height = height
 }

 // 原生对象默认不是可迭代对象，需要自己实现Symbol.iterator方法
 // 在原型上实现，确保所有实例都是可迭代对象
 [Symbol.iterator]() {
  const values = Object.values(this)
  let index = 0

  return {
    next: () => {
      if (index < values.length) {
        return { done: false, value: values[index++] }
      } else {
        return { done: true }
      }
    }
  }
 }
}

const p1 = new Person('Klaus', 23, 1.88)

for (const value of p1) {
  console.log(value)
}

/*
  =>
    Klaus
    23
    1.88
*/
```



## 中断

迭代器在某些情况下会在没有完全迭代的情况下中断:

+ 比如遍历的过程中通过break、return、throw中断了循环操作
+ 比如在解构的时候，没有解构所有的值

```js
const user = {
  name: 'Klaus',
  age: 23,
  height: 1.88,
  [Symbol.iterator]() {
    const values = Object.values(user)
    let index = 0

    return {
      next() {
        if (index < values.length) {
          return { done: false, value: values[index++] }
        } else {
          return { done: true }
        }
      },

      // 没有return方法，则默认会存在return方法
      // 有return方法，会对默认的return方法进行重写
      return() {
        // 可以在中断时执行自定义逻辑
        console.log('迭代器被中断了')
        return { done: true } // return 返回对象的格式和next方法返回的对象格式完全一样
      }
    }
  }
}

for (const value of user) {
  console.log(value)
  if (value === 23) {
    break
  }
}
```
