## isProxy

检测是否通过以下方法创建的代理对象：

1. `reactive()`
2. `readonly()`
3. `shallowReactive()` 
4.  `shallowReadonly()` 

```js
import { isProxy, reactive, readonly, shallowReadonly, shallowReactive } from 'vue'

console.log(isProxy(reactive({ name: 'John Doe' }))) // true
console.log(isProxy(shallowReactive({ name: 'John Doe' }))) // true
console.log(isProxy(readonly({ name: 'John Doe' }))) // true
console.log(isProxy(shallowReadonly({ name: 'John Doe' }))) // true
```



## isReactive

检测是否通过以下方法创建的代理对象：

1. `reactive()` 
2. `shallowReactive()` 

```js
import { reactive, shallowReactive, isReactive } from 'vue'

console.log(isReactive(reactive({ name: 'John Doe' }))) // true
console.log(isReactive(shallowReactive({ name: 'John Doe' }))) // true

// readonly方法包裹的reactive对象，也可以通过isReactive方法检测
console.log(isReactive(readonly(reactive({ name: 'Klaus' })))) // true
```



## isRef

检查某个值是否为 ref

```js
import { ref, isRef } from 'vue'

console.log(isRef(ref({ name: 'John Doe' }))) // true
```

## toRaw

根据一个 Vue 创建的代理返回其原始对象

```js
import { reactive, toRaw } from 'vue'

const foo = { name: 'Klaus', friend: { name: 'John' }}
const reactiveFoo = reactive(foo)

console.log({...reactiveFoo}) 
// 浅层获取原始对象 => {name: 'Klaus', friend: Proxy({name: 'John'})}

console.log(toRaw(reactiveFoo)) 
// 深层获取原始对象 => {name: 'Klaus', friend: {name: 'John'}}
```
