## reactive

1. 参数应该只能是引用类型值 
   + proxy只能代理引用类型值 
   + 如果是普通对象会报警告
2. 返回值是proxy代理
3. 是深度代理 「 递归，对每一层引用类型都使用proxy实现代理 」

> `data option` 底层使用的就是`reactive`

```js
import { reactive } from 'vue'

const userInfo = reactive({
  name: 'Klaus', // 修改 => 触发响应式
  friend: {
    name: 'John' // 修改 => 触发响应式
  }
})
```



### shallowReactive

浅层reactive对象

```js
import { shallowReactive } from 'vue'

const userInfo = shallowReactive({
  name: 'Klaus', // 修改 => 触发响应式
  friend: {
    name: 'John' // 修改 => 不触发响应式
  }
})
```



## ref

1. 可以传入任何类型数据 「  弥补reactive只能响应式引用类型缺陷 」
2. 返回值是`RefImpl`实例
3. 本质: `源 => { value: 处理后的代理 }`
   + 在模板中使用会自动解包
   + 在脚本中使用要通过value属性
   + 在模板中使用
     1. 浅层ref 「 直接修改ref 」会自动解包
     2. 深层ref 「  ref做为对象的属性使用并修改 」并不会自动解包
4. 如果参数传人引用类型 => `引用类型 =>  { value: reactive(引用类型) }`

```vue
<template>
  <div>
    <div>
      <!-- 使用时，都能自动解包 -->
      <span>{{ count }}</span>
      <!-- 浅层修改 自动解包 -->
      <button @click="count++">+1</button>
    </div>

    <div>
      <!-- 使用时，都能自动解包 -->
      <span>{{ counter.count }}</span>
      <!-- 深层修改，需要手动解包 -->
      <button @click="counter.count.value++">+1</button>
    </div>
  </div>
</template>

<script>
import { ref } from 'vue'

export default {
  setup() {
    let count = ref(100)
    const counter = { count: ref(300) }

    return {
      count,
      counter
    }
  }
}
</script>
```



### shallowRef

```js
import { shallowRef } from 'vue'

const userInfo = shallowRef({
  name: 'Klaus',
})

// ref的本质是 { value: <值> } => 整体替换值才能触发响应式，直接修改属性并不会触发响应式
userInfo.value.name = 'John' // 不会触发响应式
userInfo.value = { // 会触发响应式
  name: 'John',
  age: 18
}
```

```vue
<template>
  <div>
    <h2>{{ userInfo }}</h2>
    <button @click="handleClick">click me</button>
  </div>
</template>

<script setup>
  import { shallowRef, triggerRef } from 'vue'

  const userInfo = shallowRef({
    name: 'Klaus',
  })

  function handleClick() {
    userInfo.value.name = 'John'
    // 手动触发shallowRef的依赖 => 触发响应式
    triggerRef(userInfo)
  }
</script>
```



### customRef

创建一个自定义的 ref

```js
import { customRef } from 'vue'

// 使用示例 -> useDebounceRef('Hello Wolrd', 1000)
// 功能 -> 延时更新 「 自带节流功能 」
export default function(value, delay = 2000) {
  // 返回一个自定义的ref实例对象
  return customRef((track, trigger) => {
    let timer = null

    return {
      set(newValue) {
        if (timer) {
          clearTimeout(timer)
        }

        // 设置值
        timer = setTimeout(() => {
          value = newValue // 新值覆盖旧值
          trigger() // 触发更新
        }, delay)
      },

      get() {
        // 收集依赖 (dependencies 简写为 deps）
        track()
        return value
      }
    }
  })
}
```



## readonly

1. 参数为 `普通对象 | ref对象 | reactive对象`
2. 返回只读proxy实例 「 劫持了set方法 」
3. readonly是深度只读 「 递归实现 」
4. 一般用于props，以保证单向数据流

```js
import { readonly } from 'vue'

const user = readonly({
  name: 'John Doe',
  age: 30,
  friends: ['Sarah Li', 'Bob Smith']
})

user.name = 'Alex Smith'
console.log(JSON.stringify(user)) 
// {"name":"John Doe","age":30,"friends":["Sarah Li","Bob Smith"]}

user.friends.push('Charlie Brown')
console.log(JSON.stringify(user)) 
// {"name":"John Doe","age":30,"friends":["Sarah Li","Bob Smith"]}
```

import { shallowReadonly } from 'vue'

## toRef

1. 可以将值、refs 或 getters 规范化为 refs
2. 基于响应式对象上的一个属性，创建一个对应的 ref。
   + 这样创建的 ref 与其源属性保持同步：改变源属性的值将更新 ref 的值，反之亦然。



**规范化签名**

```js
toRef(existingRef) // 按原样返回现有的 ref

toRef(() => props.foo) // 返回只读ref，取值时会执行getter

toRef(1) // 创建一个ref，等价于 ref(1)
```



**对象属性签名**

```js
const state = reactive({
  foo: 1,
  bar: 2
})

// 双向 ref，会与源属性同步
const fooRef = toRef(state, 'foo')

// 更改该 ref 会更新源属性
fooRef.value++
console.log(state.foo) // 2

// 更改源属性也会更新该 ref
state.foo++
console.log(fooRef.value) // 3


// 独立ref，不会与源属性同步 => 因为这个 ref() 接收到的是一个纯数值
const fooRef1 = ref(state.foo)
```



## toRefs

将一个响应式对象转换为一个普通对象

1. 这个普通对象的每个属性都是指向源对象相应属性的 ref
2. 每个单独的 ref 都是使用 `toRef` 创建的

```js
const state = reactive({
  foo: 1,
  bar: 2
})

const stateAsRefs = toRefs(state)
/*
stateAsRefs 的类型：{
  foo: Ref<number>,
  bar: Ref<number>
}
*/

// 这个 ref 和源属性已经“链接上了”
state.foo++
console.log(stateAsRefs.foo.value) // 2

stateAsRefs.foo.value++
console.log(state.foo) // 3
```



## unref

如果参数是 ref，则返回内部值，否则返回参数本身。

这是 `val = isRef(val) ? val.value : val` 计算的一个语法糖

```js
function useFoo(x: number | Ref<number>) {
  const unwrapped = unref(x) // type unwrapped => number
}
```



## toValue

1. 将值、refs 或 getters 规范化为值
2. 功能类似于 `unref` 
   + 不同的是此函数也会规范化 getter 函数
   + 如果参数是一个 getter，它将会被调用并且返回它的返回值

```js
toValue(1) //       --> 1
toValue(ref(1)) //  --> 1
toValue(() => 1) // --> 1
```
