## 编程语言

计算机语言是人为规定，用于向计算机发送指令以完成特定功能的语言。它包括多种类型，如编程语言、标记语言、样式语言等。

**编程语言**是指能够操作数据并实现业务逻辑的语言。像 **HTML** 和 **CSS** 这样的语言，虽然属于计算机语言，但它们主要用于定义页面结构和样式，无法直接实现逻辑控制或交互，因此通常被归类为 **标记语言** 和 **样式语言**，而非编程语言。



编程语言的特点包括：

1. **数据和数据结构**：可以定义数据以及存储数据的容器。

2. **指令和流程控制**：可以控制程序的执行流程，包括顺序、循环、分支等。

3. **引用机制和重用机制**：支持代码的组织和重用，例如通过函数、类、模块、库等方式减少代码冗余。

4. 设计哲学

   ：编程语言通常体现特定的设计哲学「 设计思想 」，例如：

   - 面向对象编程（OOP）
   - 函数式编程（FP）
   - 面向过程编程（POP）
   - 声明式编程
   - 事件驱动编程



## 语言发展

**早期的语言**：更接近机器的思维方式。最初的计算机只能理解二进制代码（0和1），因此早期的语言也更贴近硬件。

**现代语言**：更接近人类的思维方式。随着技术的发展，编程语言逐渐向自然语言靠拢，变得更易于人类理解和使用。

使用现代语言编写的代码，需要经过编译或解释或JIT「 实时编译和解释 」来将代码转换成机器可以理解的二进制代码，并由硬件「 CPU 」执行

+ 阶段一：机器语言
  + 由二进制代码（0和1）组成
  + 可以直接被计算机硬件执行，效率非常高
  + 可读性和易用性极差 => 编写机器语言程序不仅容易出错，而且维护起来非常困难。
+ 阶段二：汇编语言
  + 汇编语言使用符号「 助记符 」代替了机器语言中的二进制代码
  + 相对机器语言更易于理解，但它仍然与硬件紧密相关，移植性差，且编写和调试的难度较大
+ 阶段三：高级语言
  + 简单易用，语法接近自然语言，便于学习和理解。
  + 远离硬件操作，普通开发者无需了解底层硬件即可编写程序
  + 跨平台性强，代码可以运行在不同的操作系统和设备上
  + 需要经过编译或解释，无法直接被硬件识别，可能带来性能损耗
    + 现代编辑器提供的优化操作已经将这部分性能消耗降低到最低，几乎可以忽略不计
  + 种类繁多，不同的开发场景需要学习不同的语言。目前没有一门语言能够覆盖所有的应用领域。



## JavaScript

JavaScript（缩写为 JS）是一种高级的编程语言，通常被称为解释型语言。

+ 不过在现代的 V8 引擎中，使用了JIT技术，所以JavaScript可以被看成半编译半解释语言

JavaScript 是一门基于原型的、支持头等函数的多范式语言

+ 它支持面向对象编程、指令式编程和函数式编程

JavaScript是脚本语言，需要运行于特定的宿主环境

+ 常见的宿主环境有 浏览器 和 node



### 发展史

史上第一个成熟的网络浏览器  **Navigator 浏览器** 最开始发布时，只能用来浏览静态网页，无法与用户进行交互。「 即对用户操作做出反应 」

在 1995 年，网景公司聘请了程序员 **Brendan Eich**，希望他能将一种现有的编程语言嵌入到浏览器中。Brendan Eich 对 **Scheme** 语言非常熟悉，因此网景公司最初打算使用 Scheme 作为浏览器的脚本语言。

但在同一年，Sun 公司发布了 **Java**（原名 Oak）。Java 的口号是“Write Once, Run Anywhere”（一次编写，到处运行），这让 Java 在市场上引起了轰动。网景公司也对 Java 产生了兴趣，并希望与 Sun 公司合作，将 Java 嵌入到浏览器中。

然而，Brendan Eich对 Java 并不感兴趣，他更倾向于使用 Scheme。最终，他用了短短十天时间设计了一门新的语言——JavaScript。这门语言最初被命名为 **Mocha**，后来改名为 **LiveScript**，最终为了蹭 Java 的热度，正式命名为 **JavaScript**。

#### JavaScript 的设计特点

JavaScript 的设计融合了多种语言的特点：

1. **C语言**：借鉴了 C 语言的基本语法。
2. **Java**：采用了类似 Java 的数据类型和内存管理机制（如垃圾回收）。
3. **Scheme**：将函数提升为头等公民，支持函数式编程。
4. **Self**：基于原型的继承机制。

这些语言的特点被融合到 JavaScript 中，使它成为了一种“大杂烩”式的语言。Brendan Eich 曾形容 JavaScript 是 C 和 Self 的“一夜情”产物，并引用英国文学家的话说：“它的优秀之处并非原创，它的原创之处并不优秀。”



### ECMAScript

JavaScript 推出后，网景公司在其 Navigator 2.0 浏览器中采用了这门语言。与此同时，微软为了与网景竞争，推出了 **Internet Explorer（IE）** 浏览器，并逆向工程了 JavaScript 的解释器，开发了类似的语言 **JScript**。

由于同时存在 JavaScript 和 JScript，开发者不得不针对不同浏览器编写不同的代码，这对开发工作造成了很大的困扰。为了解决这个问题，网景公司在 1996 年将 JavaScript 提交给 **欧洲计算机制造商协会（ECMA）**，希望制定一个统一的标准。

1997 年，ECMA 发布了第一个 JavaScript 标准——**ECMAScript** 「 ECMA-262 」。ECMAScript 是一种语言规范，而 JavaScript 是该规范的实现之一。除此之外，还有其他实现，比如 **ActionScript** 和 **JScript**，但目前最流行的实现仍然是 JavaScript。



### 组成

JavaScript是一种脚本语言。而脚本语言一般是解释型语言，一般用于控制某些软件以实现特定的功能，而不具备调用操作系统功能的能力。而被其控制的软件被称之为对应脚本语言的宿主环境

所以对于JavaScript的规范ECMA-262而言，只约定了最基本的基本语法。并没有规定如何和宿主环境进行交互。因为不同宿主环境提供的功能 「 API 」是不一样的

就浏览器而言，JavaScript可以由以下三部分组成

1. **ECMAScript**：语言的核心规范。
2. **DOM**：网页操作相关的功能。
3. **BOM**：浏览器操作相关的功能。

> 网页并不是浏览器的一个组成部分
>
> 浏览器只是下载并解析网页，生成对应的DOM，并渲染在浏览器的视口中
>
> 所以DOM和BOM是完全独立的两部分内容，DOM并不是BOM的一部分



### 版本

1. **2009年**：发布 ECMAScript 5（ES5），这是一个重要版本，增加了许多新特性，比如严格模式（`use strict`）。
2. **2015年**：发布 ECMAScript 2015（ES6），也称为 ES6。它引入了大量新特性，比如箭头函数、`let` 和 `const`、模块化等。
3. ES6开始将JS拆分成了多个模块，每年六月统一根据模块进行更新，而不再发布大版本

> ES2024这种是为了方便区分版本的民间叫法，不是官方叫法

### 编写位置

1. **行内编写**
   + 通过 HTML 标签的属性（如 `onclick`）直接编写 JavaScript 代码，不推荐使用。
   + 属性名全小写
   + 如果存在自定义行为会优于默认行为执行
2. **`<script>` 标签内编写**：将 JavaScript 代码写在 HTML 文件的 `<script>` 标签中，适合简单的页面开发。
3. **独立的 JavaScript 文件**：将 JavaScript 代码写在独立的 `.js` 文件中，并通过 `<script>` 标签的 `src` 属性引入，推荐在实际开发中使用。
4. **@import**: 在css文件中引入另一个css文件
   + 和前几种方式不同，前几种加载可以并行，而`@import`加载是串行的
   + 且`@import`前面只能有注释和别的`@import`
