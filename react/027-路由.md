React 因为它能够支持多端开发，以 React 为核心的生态也分成了两个部分：

- `react-dom`，是专门处理 Web 端的开发；
- `react-native`，是专门处理原生 APP 的开发。

同样，React 的路由库也分成了两部分：

- `react-router-native`，用于原生 APP 的路由管理；
- `react-router-dom`，用于 Web 端的路由管理。



多页面应用「 MPA 」，就是整个项目由多个页面组成的

+ 传统开发
+ 点击后页面整体刷新或开新页面

单页面应用 「 SPA 」=> 页面局部刷新

+ 通过不同url片段 来标识应该渲染什么组件
+ 不同url片段就是路由

现代前端开发基本都是SPA为主，MPA为辅。即基本都是单页面应用，只不过部分单个页面会开启新页签



前端路由机制 => 在点击某些操作时，通过在路由地址或哈希值等相关信息发生变化时，动态地渲染我们想要呈现的组件。从而保证整个页面不跳转的情况下，我们可以让页面不断地呈现出不同的效果



SPA缺点

1. 首屏空白加载过长
2. 不利于SEO



实现路由的方式

1. hash路由
2. history路由
