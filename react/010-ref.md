`componentDidMount` 是在组件第一次渲染完成后触发的一个生命周期方法，我们可以在这里通过原生dom提供的JavaScript API获取到 DOM 元素。



`ref引用`的特点

1. `ref引用`必须在`componentDidMount`及以后的生命周期中才可以获取
2. 引用对应的DOM，在实际渲染前或被销毁后是获取不到实际值的



## 字符串形式Ref

> 自React19开始，字符串形式ref已经被移除，无法再使用
>
> 原因是 字符串形式ref在底层实现时 => 繁琐，性能低且可读性差

```jsx
import React, { PureComponent } from 'react'

export class App extends PureComponent {
  render() {
    return (
      <>
        {/* 这个ref属性也会存在于vdom的props属性中，并没有被移除 */}
        <div ref="root">App</div>
      </>
    )
  }

  componentDidMount() {
    console.log(this.$refs) // { root: DOM }
    console.log(this.$refs.root) // <div ref="root">App</div>
   }
}

export default App
```



## 函数形式Ref

```jsx
import React, { PureComponent } from 'react'

export class App extends PureComponent {
  // 不参与界面渲染的普通数据，没有必要挂载到state中
  divEl = null

  render() {
    return (
      <>
        {/* 这个函数会在组件dom更新时执行 => 如初始渲染，DOM更新，组件卸载 */}
        <div ref={ dom => this.divEl = dom }>App</div>
      </>
    )
  }

  componentDidMount() {
    console.log(this.divEl)
  }
}

export default App
```

```jsx
import React, { PureComponent } from 'react'

export class App extends PureComponent {
  // 通过这种方式可以批量获取对应dom元素
  divEls = []

  render() {
    return (
      <>
        <div ref={ dom => this.divEls.push(dom) }>Vue</div>
        <div ref={ dom => this.divEls.push(dom) }>React</div>
        <div ref={ dom => this.divEls.push(dom) }>Angular</div>
        <div ref={ dom => this.divEls.push(dom) }>Svelte</div>
      </>
    )
  }

  componentDidMount() {
    console.log(this.divEls) // [div, div, div, div]
  }
}

export default App
```



## createRef

```jsx
import { PureComponent, createRef } from 'react'

export class App extends PureComponent {
  // createRef返回的是带有current属性的对象 => 这个对象被叫做Ref对象
  // 参数是可选的，不传参数时，返回的ref对象的current属性初始值为null
  // 传入参数时，返回的ref对象的current属性初始值为传入的参数
  divEl = createRef()

  render() {
    return (
      <>
        <div ref={ this.divEl }>App</div>
      </>
    )
  }

  UNSAFE_componentWillMount() {
    console.log(this.divEl) // {current: null}
  }

  componentDidMount() {
    console.log(this.divEl) // {current: div}
  }
}

export default App
```



## 获取组件

```jsx
import { PureComponent, createRef, forwardRef } from 'react'

class ClassCpn extends PureComponent {
  render() {
    return <div>ClassCpn</div>
  }
}

const BaseFuncCpn = () => <div>FuncCpn</div>

// 通过forwardRef实现ref的状态 => 目的就是为了获取函数组件内部的某个元素
// 函数组件被forwardRef包装后，会在原有props参数的基础上，多一个ref参数
// ref参数的值是父组件传入的ref
const FuncCpn = forwardRef((props, ref) => {
  // ref={ ref } 不能简写为 { ref } => react不支持简写
  return <div ref={ ref }>FuncCpn</div>
})

export class App extends PureComponent {
  classEl = createRef()
  baseEl = createRef()
  funEl = createRef()

  render() {
    return (
      <>
        <ClassCpn ref={ this.classEl } />
        {/*
          在React19之前，函数组件必须结合forwardRef才可以获取到dom，否则直接报错
          自React19开始，函数组件可以不结合forwardRef使用，只不过此时获取不到dom 「 但不报错了 」
        */}
        <BaseFuncCpn ref={ this.baseEl } />
        <FuncCpn ref={ this.funEl } />
      </>
    )
  }

  componentDidMount() {
    // 作用于类组件获取的是类组件实例
    console.log(this.classEl) // {current: ClassCpn}
    console.log(this.baseEl) // {current: null} => 没有ref转发，不报错，但值为默认值
    console.log(this.funEl) // {current: div} => 存在ref转发，正常获取DOM元素
  }
}

export default App
```

```jsx
import { PureComponent, createRef } from 'react'

class ClassCpn extends PureComponent {
  // 在类组件中，模拟Ref转发
  divEl = createRef()

  render() {
    return <div ref={ this.divEl }>ClassCpn</div>
  }
}

export class App extends PureComponent {
  classEl = createRef()

  render() {
    return (
      <>
        <ClassCpn ref={ this.classEl } />
      </>
    )
  }

  componentDidMount() {
    console.log(this.classEl.current.divEl) // {current: div}
  }
}

export default App
```
