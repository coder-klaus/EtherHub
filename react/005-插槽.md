组件双闭合调用，传入的子节点会作为`props.children` 

`children`值可能存在如下三种情况:

1. 如果没有传递子节点，`children` 的值是 `undefined`。
2. 如果只传递了一个子节点，`children` 的值是该子节点本身（可能是文本节点或 React 元素节点）。
3. 如果传递了多个子节点，`children` 的值是一个数组，包含所有的子节点。

```jsx
export default function App({ children }) {
  return (
    <>
      {/*
        1. 没有children => undefined => 什么都不渲染
        2. 只有一个子节点 => 该子节点被渲染
        3. 多个子节点 => 数组元素项依次取出并进行渲染 
      */}
      {children}
    </>
  )
}
```



属性和插槽其实本质上是相似的，它们的核心目的都是为了在**父组件调用子组件时，把一些信息传递给子组件**。

唯一的区别在于：**属性传递的是数据，插槽传递的是结构**。所以如果**传递数据用属性，传递结构用插槽** 

可以将插槽 「 slot 」看成是一种特殊的属性「 props 」





## React.Children

`Children` 是 React 提供的一个工具对象，里面有一些非常实用的方法：

- **`count`**：用来统计子元素的数量。
- **`forEach`**：用来对子元素进行循环操作。
- **`map`**：用来对子元素进行映射，返回一个新的子元素数组。
- **`only`**：用来确保子元素中只有一个唯一的子节点，否则会抛出错误。
- **`toArray`**：将子元素转换为一个数组，方便操作。

> 因为数组可能存在三种情况，所以建议以后的话，如果你想处理插槽的话，进来的第一件事就是把它变成数组



## 具名插槽

::: code-group

```jsx [父组件]
import { createRoot } from 'react-dom/client'
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <App>
    {/* 这里的slot是自定义的属性名，叫啥都行 */}
    <header slot="header">header1</header>
    {/* slot加在对应插槽元素的根节点上 */}
    <header slot="header">header2</header>
    <footer slot="footer">footer</footer>
  </App>
)
```

```js [子组件]
import React from "react"

export default function App({ children }) {
  // 确保无论是否传递插槽, props.children都是数组
  const slots = React.Children.toArray(children)

  // 之所以定义为数组，是因为可能存在多个同名插槽
  // 当前也可以定义defaultSlot，用来存放所有未匹配的插槽 「 即默认插槽 」
  const headerSlot = []
  const footerSlot = []

  // 如果父组件的 VDOM 中包含子组件，React 会在解析父组件的 VDOM 时递归地渲染子组件
  // 因此，从逻辑上看，子组件的渲染会发生在父组件的渲染过程中，所以props.children中存入的不是标签，而是vdom
  slots.map(v => {
    // 解构处slot，剩余props 组合成新的props
    const { slot, ...newProps } = v.props

    // React.cloneElement(源元素， props对象， ...子节点)
    // 基于现有的元素，克隆一个新元素
    // 1. 参数一 => 需要克隆的元素
    // 2. 参数二 => props「 可选 」 => 适合源元素的props合并，不是替换
    // 3. 参数三及以后 => 新的子节点 「 是替换，不是合并 」
    const elem = React.cloneElement(v, {
      ...newProps,
      slot: undefined // 设置属性值为undefined或null，在渲染时会被react自动移除
    })

    if (slot === 'header') {
      headerSlot.push(elem)
    } else if (slot === 'footer') {
      footerSlot.push(elem)
    }
  })

  // 设置插槽默认值
  if (!headerSlot.length) {
    headerSlot.push(<div>这是默认header</div>)
  }

  if (!footerSlot.length) {
    footerSlot.push(<div>这是默认footer</div>)
  }

  return (
    <>
      <div>{headerSlot}</div>
      <div>content</div>
      <div>{footerSlot}</div>
    </>
  )
}
```
