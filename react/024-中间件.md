中间件的作用是：在动作派发到 reducer 之前，先经过中间件处理。中间件处理完成后，再去通知 reducer，最终完成状态的修改。也就是说，原本直接派发到 reducer 的过程，现在需要先经过中间件。



## redux-logger

在每一次派发（dispatch）动作时，在控制台输出日志。也就是说，每次派发都会在控制台输出派发的日志。

Redux Logger 在控制台输出的内容主要包括：派发前的状态（previous state）、派发的动作（action），以及派发后的状态（next state）

```js
import { createStore, applyMiddleware } from 'redux'
import reducer from './reducer'
import logger from 'redux-logger'
import { thunk } from 'redux-thunk'

// 通过applyMiddleware来使用中间件
// 对于redux-logger 只要安装就会自动生效
const store = createStore(reducer, applyMiddleware(logger, thunk))

export default store
```



## 异步派发

如果不使用任何中间件，Redux 的 `action creator` 返回的对象是不支持异步操作的。

派发的时候 `action对象`必须是一个普通的JavaScript对象



### Redux Thunk 「 官方推荐 」

1. 通过`applyMiddleware`进行安装
2. 调整`dispatch`方法的调用



如果我们返回的是一个普通对象，Redux 会直接处理它。

但如果我们返回的是一个函数，`Redux Thunk` 中间件会拦截并执行这个函数



总结一下，当我们使用 `Redux Thunk` 中间件时，异步操作的流程是这样的：

1. 第一次派发的是一个函数，这个函数被 `Redux Thunk` 中间件拦截。
2. 在函数内部执行异步操作。
3. 异步操作完成后，手动派发一个普通的 `action` 对象。

```js
import { COUNT_INCREMENT, COUNT_DECREMENT } from '../actionType'

// 模拟异步请求
function delay(time = 1000) {
  return new Promise(resolve => {
    setTimeout(() => {
      console.log('delay', time)
      resolve()
    }, time)
  })
}

export default {
  // 点击按钮触发increment
  // 方法返回一个方法，redux-thunk拦截并await执行
  // 执行完毕后，需要再异步方法中自己手动进行dispatch派发 「 真正的派发操作 」
  increment: payload => async (dispatch, getState) => {
    await delay()
    dispatch({
      type: COUNT_INCREMENT,
      payload
    })
  },
  // redux-thunk在执行的时候，会将dispatch和getState作为参数传入
  decrement: payload => async (dispatch, getState) => {
    await delay()
    dispatch({
      type: COUNT_DECREMENT,
      payload
    })
  }
}
```



### Redux Promise

1. + 功能和 `redux-thunk`类似，两者可以二选一使用，不需要同时安装。
     - 如果同时使用 `redux-thunk` 和 `redux-promise`Redux 会根据中间件的顺序，链式地处理异步操作
     - 一个中间件无法处理的操作，会传递给下一个中间件。
2. `redux-promise`使用相对于`redux-thunk`而言，更为简便



**使用方式**

通过`applyMiddleware`进行安装后，使用方式如下

```js
import { COUNT_INCREMENT, COUNT_DECREMENT } from '../actionType'

// 模拟异步请求
function delay(time = 1000) {
  return new Promise(resolve => {
    setTimeout(() => {
      resolve()
    }, time)
  })
}

export default {
  // 使用redux-promise后可以直接返回promise对象
  // 如果是promise对象，redux-promise会自动await等到异步执行完成后，自动调用dispatch进行派发
  // 所以如果使用redux-promise，方法必须返回一个标准的action对象
  increment: async payload => {
    await delay()
    return {
      type: COUNT_INCREMENT,
      payload
    }
  },
  decrement: async payload => {
    await delay()
    return {
      type: COUNT_DECREMENT,
      payload
    }
  }
}
```
