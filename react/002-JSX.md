JSX 「 JavaScript XML 」是 JavaScript的一种语法扩展。我们可以在JSX中编写JS 和 类HTML「 XML 」结构

在JSX中，只要是组件或元素标签 最终都会被转换为 VDOM对象。简单来说JSX中的类HTML结构本质是VDOM的语法糖写法。看似是通过JavaScript操作HTML，实际依旧是通过JavaScript操作JavaScript对象



JSX中插入动态数据使用`{ expression }` 「 插值语法、胡子语法、大胡子语法 」

中间可以插入的值是任何合法的JavaScript表达式，会将计算后的值插入对应位置

1. 变量 / 值
2. 数学运算
3. 三环运算符
4. `map`、`filter`等高阶函数 「 所有的命令式循环都不是合法的JavaScript表达式 」



## 语法细节

1. JSX 有且只能有一个根元素
   + 为了避免增加额外DOM层级，可以考虑使用 空文档标记标签 「 `React.Fragment` 」
   + `Fragment` 是 React 提供的一种特殊组件，它的作用是允许我们在不添加额外 DOM 元素的情况下，返回多个子元素 => 它是一个逻辑元素，仅用于元素包裹，不会出现在渲染后的结构中
   + `<React.Fragment></React.Fragment>` 可以简写为`<></>`
   + 只不过前者可以添加属性「 例如`key` 」, 而后者的简写写法不能添加任何属性
2. 调用可以使用单闭合，也可以使用双闭合
   + 单闭合必须严格闭合 「 JSX中X是xml，语法规则更严格 」



## 可以渲染的值

**基本数据类型**

1. `number | string` => 渲染为对应字符串
2. 其余类型 => 什么都不渲染 「 布尔类型，无论true还是false都不进行任何渲染 」



**引用数据类型**

1. 数组 => 依次取出每一项元素值进行渲染
2. 其余引用类型 => 不能渲染，直接报错
   + ReactChild对象 => 可以直接渲染
   + 样式对象 => 必须使用对象格式



## 基本样式设置

```jsx
{/* 字符串格式的style在react中是不被支持的，会报错 => 必须写成样式对象 */}
<h1 style="color: red;">我在学习 React</h1>
```

```jsx
export default function App(props) {
  return (
    // 这里是JS部分，使用普通JS注释
    <>
     {/*
       这里是JSX部分，使用JSX注释
       {}中可以放入任何合法的JSX表达式和注释
       但//会将}一起注释掉
       所以JSX只有单行注释
     */}

     {/*
       样式对象的key推荐写成小驼峰，中划线也可以但会出现警告
       样式对象的value可以省略单位，react编译时会在合适的属性值后边加上px作为单位
     */}
      <h1 style={{
        color: "red",
        backgroundColor: "black",
        'font-size': 20
      }}>Hello World!</h1>
    </>
  )
}
```

```jsx
<>
  {/* for 和 class 和 JavaScript关键字冲突，需要使用JSX别名 */}

  <input type="text" id="name" className="username" />

```

```jsx
{/* JSX不像vue那样支持动态样式和普通样式共存 => 需要手动进行字符串拼接 */}

```

## 列表渲染

```jsx
<>
  {
    // {} 中普通JavaScript，所以使用JS注释
    // react列表循环也需要加上key「 唯一, 恒定的 number 或 string 」=> 用于提升DOM-DIFF性能
    users.map(user => <div key={user}>{user}</div>)
  }

```

```jsx
<>
  {
    // 迭代生成 1 到 10 的数字
    // fill是因为new Array(10) 生成的是长度为10的纯稀释数组 「 [empty * 10] 」

  }
```

## 底层渲染机制

### 虚拟DOM

虚拟 DOM 对象「 Virtual DOM 」指的就是框架自己内部构建的一套对象体系。

这个对象体系包含了许多属性和属性值，它基于这些属性，去描述我们所构建视图中的 DOM 节点的相关特征和特点

+ 只包含了必要的属性和方法，比DOM轻量级
+ 虚拟DOM和真实DOM一一对应，也是树结构
+ 可以保存新旧VDOM，进行DOM-DIFF 提升性能，同时方便进行调试「 devtool 」
+ VDOM作为中间产物，可以实现跨平台渲染
+ VDOM可以叫做虚拟 DOM、 JSX 元素、React Child 对象



第一次渲染页面是直接从 virtual DOM -> 真实 DOM；

但是后期视图更新的时候，需要经过一个 DOM-DIFF 的对比，计算出补丁包 PATCH（两次视图差异的部分），把 PATCH 补丁包进行渲染



JSX编译的两个步骤

1. 将 **JSX** 转换为 **React.createElement** 的代码格式
   + 通过`babel-preset-react-app`这个库实现的
   + 这个库包含了`@babel/preset-env + @babel/preset-react`对应的功能
2. React 调用 **React.createElement** 方法，生成 **Virtual DOM**。



`React.createElement(组件名，props对象， ...子组件)`

+ 组件名 可以是 字符串形式的元素名，或函数组件名 或类组件名
+ 如果没有props对象，可以传入null => 但是VDOM中的props对象默认值是空对象
+ 第三个参数及之后的参数都是子组件，会被挂载到`props.children`属性中
  + 如果只有只有一个子节点，该子节点会直接挂载
  + 如果存在多个子节点，这多个子节点会变成数组后进行挂载
  + 如果没有子节点，`props.children`对应的值就是undefined 「 即没有第三个参数及以后参数 」

> 只要是元素标签，它就一定会用 **React.createElement** 来处理

```js
// 没有任何属性，也没有任何子节点 => props 也是一个空对象
function createElement(ele, props = {}, ...children) {
  if (children.length) {
    props.children = children.length === 1 ? children[0] : children
  }

  return {
    $$typeof: Symbol.for('react.element'),
    type: ele,
    ref: null,
    key: null,
    props
  }
}
```

```jsx
// 暂不考虑组件，仅考虑普通html元素情况

// DOM操作 = 页面DOM结构「 HTML 」 + 内存DOM结构 「 JavaScript 」
// + 内置属性 => 两者连通 「 例如 修改页面DOM结构，内存DOM结构也会跟着变化 」
//   + 无论是通过点语法操作，还是通过setAttribute操作，都会导致两者连通
// + 自定义属性
//   + 点语法方式 => 内存DOM结构更新，页面DOM结构不会更新
//   + setAttribute方式 => 页面DOM结构更新，内存DOM结构不会更新

// 所以在操作DOM结构的时候，点语法和attribute操作系列API 「 setAttribute, getAttribute, removeAttribute 」 两者只能选其一
// 内置属性是比较特殊的，点语法和attribute操作系列API 可以混用
function render(el, container) {
  const { type, props } = el

  const ele = document.createElement(type)

  // 迭代属性的时候全都往fragment上挂载
  // Reflct.ownKeys(props) = Object.getOwnPropertyNames(props) + Object.getOwnPropertySymbols(props)
  Reflect.ownKeys(props).forEach(key => {
    if (key === 'children') {
      // 统一将children转换为数组
      const children = Array.isArray(props.children) ? props.children : [props.children]

      children.forEach(child => {
        if (/^string|number$/.test(typeof child)) {
          // 如果子节点是两个文本或数字节点，分为两个节点单独进行渲染
          const textNode = document.createTextNode(child)
          ele.appendChild(textNode)
        } else {
          // 递归渲染
          render(child, ele)
        }
      })
    } else if (key === 'style' && typeof props.style === 'object') { // 对class和style进行特殊处理
      // DOM中的style也是一个对象，所以需要通过Object.assign进行合并
      // Object.assign 是非纯函数，会修改原对象，也就是第一个参数对象
      Object.assign(ele.style, props.style)
    } else if (key === 'className') {
      // class 是 JS的关键字，如果需要通过DOM设置元素的class属性值，也需要通过className属性
      // 如果需要通过对象形式操作class，则需要通过classList属性
      ele.className = props.className
    } else {
      // 其余属性单独处理
      ele.setAttribute(key, props[key])
    }
  })

  // 迭代完毕，将fragment进行挂载
  container.appendChild(ele)
}
```
