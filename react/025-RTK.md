**Redux Toolkit (RTK)** 可以被视为对 Redux 原生写法的语法糖。RTK是官方提供的，用于简化redux在react中进行工程化开发的工具包集合

RTK 的设计目标就是简化 Redux 的使用，减少样板代码（boilerplate），并提供更现代化、更高效的开发体验。它在本质上仍然是基于 Redux 的，但通过封装和抽象，提供了更简洁的写法和更好的开发者体验。

+ **样板代码（Boilerplate Code）** 是指在编程中为完成某些功能而需要重复编写的大量固定、模板化的代码。「 又叫通用模板代码 」

在RTK中 状态模块被称之为 切片 「 slice 」。RTK中的slice合并了传统写法中的`action creator` 和 `reducer`。不需要在写成两个文件了，只需要合并为一个文件即可

```shell
pnpm add @reduxjs/toolkit
```

```js [store的入口文件]
import { configureStore } from "@reduxjs/toolkit";
import counterReducer from './features/countSlice'
import userReducer from './features/userSlice'
import logger from 'redux-logger'
import promise from 'redux-promise'
// 配置store => 传统写法都是参数传递，而RTK中基本都改成了传入配置对象
const store = configureStore({
  // reducer配置类似于 combineReducers
  reducer: {
    counter: counterReducer,
    user: userReducer
  },
  // RTK中，默认 middleware 是 [thunk] => 默认内置了redux-thunk
  // 如果需要添加额外的中间件，则此时使用自定义值覆盖默认值，所以需要显示传入redux-thunk
  // + 可以通过 getDefaultMiddleware 获取默认中间件，然后添加额外的中间件
  middleware: (getDefaultMiddleware) => getDefaultMiddleware().concat([logger, promise])
})

export default store
```

```js [couter的切片文件]
import { createSlice } from '@reduxjs/toolkit'

// 创建一个slice
const counterSlice = createSlice({
  name: 'counter', // slice名称 需要唯一
  initialState: { // 初始状态值
    value: 0
  },
  // 需要执行的操作，
  reducers: {
    // 参数为 状态 和 行为对象
    increment: (state, action) => {
      // action对象中，type是自动生成的，payload是传递的参数 「 依旧是标准的action对象 」
      // 其中type名为 => `slice名称/reducers中的方法名`
      console.log(action) // { type: 'counter/increment', payload: { step: 5 } }
      // 可以直接修改，无需拷贝，因为RTK在处理时，内置了immer
      // + immer是一个库，当我们直接修改状态时，immer会自动拷贝出一个新的状态并进行相应的修改
      state.value += action.payload.step
    },
    decrement: (state, action) => {
      state.value -= action.payload.step
    }
  }
})

console.log(counterSlice)

  actions: {
    increment: function() {},
    decrement: function() {}
  },
  caseReducers: {
    increment: function() {},
    decrement: function() {}
  },
  // 获取初始状态
  getInitialState: function() {},
  // 根据reducers中的方法，自动生成reducer

// 导出actions
export const { increment, decrement } = counterSlice.actions
// 导出reducer
export default counterSlice.reducer
```

```js [user的切片]
import { createSlice } from '@reduxjs/toolkit'

function delay (ms = 1000) {
  return new Promise(resolve => setTimeout(resolve, ms))
}

const userSlice = createSlice({
  name: 'user',
  initialState: {
    name: '张三',
    age: 18
  },
  reducers: {
    setName: (state, action) => {
      state.name = action.payload.name
    },
    setAge: (state, action) => {
      state.age = action.payload.age
    }
  }
})

// 如果需要导出的是异步action，需要自己基于原本的action进行二次封装

// 异步action => redux-thunk写法
export function setNameAsync (payload) {
  return async dispatch => {
    await delay()
    dispatch(setName(payload))
  }
}

// 异步action => redux-promise写法
export async function setAgeAsync (payload) {
  await delay()
  return {
    type: 'user/setAge',
    payload
  }
}

export const { setName, setAge } = userSlice.actions
export default userSlice.reducer
```

```jsx [Counter组件]
import { memo } from 'react'
// useSelector 和 useDispatch 是 react-redux 提供的钩子函数
import { useSelector, useDispatch } from 'react-redux'
import { increment, decrement } from './store/features/countSlice'

const Count = memo(() => {
  // 通过useSelector获取状态 「 参数state是总的state，返回对象就类似于mapStateToProps中返回的对象 」
  const count = useSelector(state => state.counter)
  // 通过useDispatch获取dispatch
  const dispatch = useDispatch()

  return (
    <div>
      <p>计数器：{count.value}</p>
      <button onClick={() => dispatch(increment({ step: 5 }))}>+</button>
      <button onClick={() => dispatch(decrement({ step: 1 }))}>-</button>
    </div>
  )
})

export default Count
```

```jsx [User组件]
import { memo } from 'react'
import { useSelector, useDispatch } from 'react-redux'
import { setAgeAsync, setNameAsync } from './store/features/userSlice'

const User = memo(() => {
  const user = useSelector(state => state.user)
  const dispatch = useDispatch()

  return (
    <div>
      <p>用户名：{user.name}</p>
      <p>用户年龄：{user.age}</p>
      <button onClick={() => dispatch(setNameAsync({ name: '李四' }))}>change name</button>
      <button onClick={() => dispatch(setAgeAsync({ age: 20 }))}>change age</button>
    </div>
  )
})

export default User
```
