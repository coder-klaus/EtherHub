对应的事件冒泡传播路径是 「 点击了`inner` 」

 `window -> document -> html「document.documentElement」 -> body「document.body」 -> root -> outer -> inner`

```js
document.documentElement.addEventListener('click', function () {
    console.log('html 捕获');
}, true);

document.documentElement.addEventListener('click', function () {
    console.log('html 冒泡');
}, false);
```



事件触发

1. 捕获阶段 「 从外到内，从window开始 」=> 主要目的 分析事件传播路径
2. 目标阶段 「 触发事件元素的捕获和冒泡 」
3. 冒泡阶段 『 从内到外，到window结束 』



事件本身是默认的行为，只要某个元素触发了事件，这个行为就会发生。事件被触发后，如果我们绑定了对应的方法，方法就会被执行；如果没有绑定方法，那事件本身虽然触发了，但什么都不会发生，仅此而已



触发了事件后可以得到事件对象，所有事件对象都是Event的子类

在Event中存在如下属性

| 属性            | 常量值 | 说明                         |
| --------------- | ------ | ---------------------------- |
| CAPTURING_PHASE | 1      | 用于判断当前事件处于捕获阶段 |
| AT_TARGET       | 2      | 用于判断当前事件处于目标阶段 |
| BUBBLING_PHASE  | 3      | 用于判断当前事件处于冒泡阶段 |

| 属性                     | 说明                                                         |
| ------------------------ | ------------------------------------------------------------ |
| preventDefault           | 阻止默认行为                                                 |
| stopPropagation          | 阻止事件传播 「 即可以阻止冒泡也可以阻止捕获 」              |
| stopImmediatePropagation | 不仅阻止事件的传播，还会阻止当前元素上其他绑定的事件处理函数的执行 |

| 属性名               | 描述 「 这三个属性都是伪数组对象 」 | 使用场景                                                 |
| -------------------- | ----------------------------------- | -------------------------------------------------------- |
| **`touches`**        | 当前屏幕上所有正在触摸的点          | 需要处理所有触摸点（如多点触控）                         |
| **`targetTouches`**  | 当前目标元素上所有正在触摸的点      | 需要处理与目标元素相关的触摸点                           |
| **`changedTouches`** | 当前触摸事件中状态发生变化的触摸点  | 需要处理触摸点的状态变化（例如新增、移动或移除的触摸点） |

| 属性名              | 含义                       | 适用场景                             |
| ------------------- | -------------------------- | ------------------------------------ |
| **`target`**        | 实际触发事件的目标元素     | 需要知道用户具体操作的元素时使用     |
| **`currentTarget`** | 当前事件处理程序绑定的元素 | 需要知道事件处理程序所属的元素时使用 |

```html
<div class="root">
  <div class="outer">
    <div class="inner"></div>

<script>
  const root = document.querySelector('.root');
  const outer = document.querySelector('.outer');
  const inner = document.querySelector('.inner');

  inner.addEventListener('click', e => {
    e.stopPropagation()
    console.log('inner clicked1');
  })

  inner.addEventListener('click', () => {
    console.log('inner clicked2');
  })

  outer.addEventListener('click', () => {
    console.log('outer clicked');
  })

  /*
    inner clicked1
    inner clicked2
  */
</script>
```

```html
<div class="root">
  <div class="outer">
    <div class="inner"></div>
  </div>
</div>

<script>
  const root = document.querySelector('.root');
  const outer = document.querySelector('.outer');
  const inner = document.querySelector('.inner');

  // 默认冒泡阶段触发，即第三个参数默认值为false
  inner.addEventListener('click', e => {
    console.log(e.eventPhase) // 2
    // 元素的目标阶段 同时包括了捕获和冒泡
    console.log(e.AT_TARGET === e.eventPhase) // true
  })

  inner.addEventListener('click', e => {
    console.log(e.eventPhase) // 2
  }, true)
</script>
```

| ------------- | ------------------------ |
| target        | 触发事件的那个事件源     |
| currentTarget | 正在执行回调的那个事件源 |

事件委托的优点

1. 简化DOM获取的数量和绑定的方法数量，减少内存消耗，提升JavaScript的运行性能
2. 把相关处理逻辑整合到了一起，内聚性更强
3. 新增元素无法单独进行事件绑定，也可以执行对应事件逻辑

> 像 `mouseenter` 或者 `mouseleave` 这样的事件，它们是没有冒泡机制的
>
> 而`mouseover`和`mouseout`存在冒泡行为

```js
const button = document.querySelector('button');

button.addEventListener('click', e => {
  // e.composedPath() 返回事件传播路径 「 事件冒泡路径 」
  // 这个属性在捕获处理函数 和 冒泡处理函数中 都存在
  console.log(e.composedPath()) // [button, body, html, document, Window]
})
```



## window 和 document

- `window` 是整个浏览器窗口的全局对象，代表浏览器的窗口或框架。
- `document` 是 `window` 对象的一个属性，表示整个网页内容（DOM，文档对象模型）

```js
window // window 对象

console.log(document);  // document对象
console.log(window.document === document); // true，说明 document 是 window 的一部分

console.log(document.documentElement) //  html元素
console.log(document.body) //  body元素
console.log(document.head) //  head元素
```
