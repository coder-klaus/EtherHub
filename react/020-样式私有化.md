React 的类组件和函数组件默认都是全局样式作用域，样式不会自动限制在组件内部「 没有样式作用域 」

任何样式（如 `.button`）都可能影响其他组件，除非开发者采取额外的措施。



主要解决方法

1. 内联样式 「 内联样式的样式优先级是最高的，仅次于 `!important` 」

   + 原生内联写法 「 style属性 」
     + 内联写法无法设置伪类或伪元素
   + tailwindcss

2. 组件根元素唯一样式名

   + 组件内元素样式都需要嵌套在最外层容器的样式类名下

   + 需要完全依靠人为有意识的去进行规范命名
   + 公共样式可以写在类似于`index.css`、`global.css`之类的样式文件中
   + 父组件样式可能会影响子组件样式
   + 这种方式无法设置动态属性值，需要和其余样式编写方式一起结合使用

   + 示例
     + 基于路由或路径 => `<路径地址 | 路由地址>-<组件名>`
     + 基于BEM（Block Element Modifier）样式命名规范 => `menu__item--active`

3. css modules

   + 这个功能依赖于构建工具
   + css模块命名一般为  `xxx.module.css` 或 `xxx.module.less`等

4. css in js

   + styled-component
   + react jss

```jsx [App.jsx]
import { memo, useState } from 'react'

  // JSX中动态类名不支持和普通类名共存，如果需要一起写需要借助模板字符串
  // 或者使用 类似于 classnames 这类第三方库 模拟 vue中对象或数组格式写法 
  return (
    <div className={`${appStyle.app} ${appStyle['hover-class']}`}>
      <h2 className={appStyle.title}>当前计数: {second}</h2>

    </div>
  )
```

```css [app.module.css]
/* 对于css module，所有的类名会被编译为唯一值，并以对象形式被导出 */
.app {
  width: 300px;
  height: 300px;
  background-color: #e6f0f5;
}

.app .title {
  color: #333;
}

	只有类名才会转换，其余样式并不会进行转换

	display: block
}

/*
	该类名在编译后，key为hover-color
	为了方便样式对象在JSX中获取对应key，使用css module的样式类名推荐使用小驼峰可以进行命名

.hover-color {
  color: #007bff;
}

.app .btn {
  background-color: #007bff;
  appearance: none;
  border: none;
}
```

## css in js

`css in js`本质是在js中编写css的一种方式，所以对应样式文件名可以是类似于`nav.style.js`或者`navStyle.js`这种格式进行命令



### react jss

```jsx
import { memo } from 'react'
import { createUseStyles } from 'react-jss'

// 通过 createUseStyles 创建一个 hook 函数
const useStyles = createUseStyles({
  name: {
    // 会自动加上px作为单位
    fontSize: 20,
    color: '#333',

    // 伪类 => 使用 & 来表示name
    // 依旧是对象的key，所以需要加上引号来使用
    '&:hover': {
      color: '#007bff'
    }
  },
  age: {
    fontSize: 16,
    color: '#666',

    '& a': {
      color: '#f00'
    }
  }
})


const App = memo(() => {
  // 通过生成的hook函数创建样式对象
  const styles = useStyles()

  return (
    <div>
      <h2 className={styles.name}>Klaus</h2>
      <h2 className={styles.age}>
        <a href="https://www.google.com">28</a>
      </h2>
    </div>
  )
})

export default App
```

```jsx
import { memo } from 'react'
import { createUseStyles } from 'react-jss'

const useStyles = createUseStyles({
  name: {
    // hook传入的参数可以通过props获取
    fontSize: props => props.fontSize,
    color: '#333',

    '&:hover': {
      color: '#007bff'
    }
  },
  // 通过函数方式获取动态值，只能
  // 1. 设置给单个属性
  // 2. 设置给一级样式值
  age: ({ color, fontSize }) => ({
    fontSize,
    color,

    '& a': {
      color: '#f00'
    }
  })
})

const App = memo(() => {
  const styles = useStyles({
    fontSize: 20,
    color: '#333',
  })

  return (
    <div>
      <h2 className={styles.name}>Klaus</h2>
      <h2 className={styles.age}>
        <a href="https://www.google.com">28</a>
      </h2>
    </div>
  )
})

export default App
```

```jsx
import React, { PureComponent } from 'react'
import { createUseStyles } from 'react-jss'

const useStyles = createUseStyles({
  name: {
    fontSize: 20,
    color: '#2196f3',
  }
})

export class App extends PureComponent {
  render() {
    const { styles } = this.props

    return (
      <div className={styles.name}>Klaus</div>
    )
  }
}

// 高阶组件 「 HOC 」 => 传入一个组件，返回一个新组件 「 和高阶函数不同，高阶组件的两个条件必须全部满足 」
// hook以useXxx命名，而高阶组件以withXxx命名
const withStyles = WrapperComponent => {
  const HOC = props => {
    const styles = useStyles(props)

    return (
      // 传递props时，需要将WrapperComponent原本的props一起进行传递，避免props的丢失
      <WrapperComponent {...props} styles={styles} />
    )
  }

  return HOC
}

// withStyles的目的是为了可以让类组件使用React-JSS的hook
// 注意: react的热更新是通过组件名进行识别，所以withStyles的返回HOC尽可能不要使用匿名组件
export default withStyles(App)
```



装饰器模式（Decorator Pattern）是一种结构型设计模式，主要用于在**不改变原有对象结构**的情况下，动态地为对象添加新的功能。它强调的是**功能的扩展**。

代理模式（Proxy Pattern）也是一种结构型设计模式，它通过一个**代理对象**来控制对目标对象的访问。它强调的是**控制访问**。

HOC的本质是通过闭包和柯里化函数方式，实现了装饰器模式，实现了组件功能的增强



### styled-components

需要语法提示，安装插件`Styled Components`

```jsx
import { memo } from 'react'
import styled from 'styled-components'

// 定义变量 「 可以抽取为单独主题变量文件 」
const BG_COLOR = '#2196f3'

// styled.<标签名>`样式`
const AppBtn = styled.button`
  background-color: ${BG_COLOR}; // 使用变量
  color: #fff;
  border: none;
  padding: 10px 20px;
  border-radius: 5px;

  /*
    子元素编写样式方式和预处理器完全一致
    所以理论上只要给根元素设置唯一标识即可
  */
  a {
    color: #fff;
    text-decoration: none;

    &:hover {
      color: #323232;
    }
  }
`


const App = memo(() => {
  return (
    <AppBtn>
      <a href="https://www.google.com">google</a>
    </AppBtn>
  )
})

export default App
```

```jsx
import { memo } from 'react'
import styled from 'styled-components'

// 样式组件可以传入props
// 通过attrs方法可以在设置时对props进行拦截，执行自定义操作，例如设置默认值
const AppBtn = styled.button.attrs(props => ({
  size: props.size || 16,
  bgColor: '#2196f3'
}))`
  background-color: ${props => props.bgColor}; // 使用props
  color: #fff;
  border: none;
  padding: 10px 20px;
  border-radius: 5px;

  a {
    font-size: ${props => props.size}px;
    color: #fff;
    text-decoration: none;

    &:hover {
      color: #323232;
    }
  }
`


const App = memo(() => {
  return (
    <AppBtn size={20}>
      <a href="https://www.google.com">google</a>
    </AppBtn>
  )
})

export default App
```
